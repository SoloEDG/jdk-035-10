# 午夜回路 · Night Circuit

## 本地启动

```bash
npm ci
npm run dev
```

## Docker 启动

```bash
docker compose up --build
```

打开 http://localhost:8035/ 。

## 闸门走廊

档案馆东侧是由三道周期闸门组成的走廊，通往撤离点：

- 每道闸门各有拍长与开窗相位，只有开窗的回合才能进入门格；已在门上的人原开窗供其走完，离开不受限。
- 踩到旁侧踏板可把指定闸门的开窗相位自下一拍起后移；巡逻的闸门岗守卫也会踩动踏板改拍。
- 点选地图格子可标出至多 3 格过廊意图，「闸门走廊」面板会给出能在既定门窗内走完的逐回合时序（允许插入等待），并在现有移动/等待按钮上高亮下一手。
- 预演计入守卫巡逻造成的改拍与进出门的实际顺序；实际走法与预演偏离后，会从实际落点自动重排余程。
